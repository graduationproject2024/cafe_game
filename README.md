# 🌴 the A&A specialty cafe & sweets | ألعاب درايف ثرو المدينة المنورة

تطبيق ويب تفاعلي متقدم مصمم خصيصاً لكافيه **the A&A specialty cafe & sweets** بالمدينة المنورة، لتقديم تجربة ترفيهية استثنائية لعملاء مسار السيارات (Drive-thru) أثناء انتظار تحضير طلباتهم، مع فرصة الفوز بجوائز وخصومات فورية وكوبونات مشفرة معتمدة.

---

## ✨ التحديثات والميزات الجديدة (v3.0)

### 1. 🏛️ الهوية البصرية وشعار the A&A وهوية المدينة المنورة
- **شعار the A&A الرسمي**: مدمج بالهيدر وبطاقات الألعاب وتذكرة الفوز.
- **خلفية ونقوش مستوحاة من المدينة المنورة**: دمج نقوش وزخارف المدينة (معالم المسجد النبوي، نخيل المدينة، دلة القهوة العربية، V60، والأواني التراثية).
- **ألوان الهوية المتناسقة**: درجات الأخضر التيل الفاخر (`#0a3a37`) مع الذهب المعتق (`#d4a017`) ولمسات رملية كريمة.
- **محتوى ثقافي وتراثي متكامل**:
  - أسئلة كويز متخصصة في تاريخ القهوة المختصة وتراث المدينة المنورة (تمر العجوة، النعناع المديني والدوش، القهوة السعودية بالهيل والزعفران، عالية المدينة).
  - تصنيف المشروبات يشمل مشروبات the A&A المختصة والمشروبات المدينية الشعبية.

---

### 2. 🚗 مستشعر أمان سرعة وحركة المركبة (Vehicle Motion & Safety Sensor)
- **كيف تتأكد اللعبة من ثبات السيارة؟**
  - **GPS Geolocation API (`navigator.geolocation.watchPosition`)**: مراقبة دقيقة ومستمرة لسرعة المركبة الحقيقية بالمتر/ثانية وتحويلها إلى (كم/ساعة)، مع حساب الفارق الزمني والمكاني بدقة Haversine.
  - **مستشعر التسارع (`window.DeviceMotionEvent`)**: رصد التسارع الخطي للمركبة لتمييز الحركة عن اهتزاز اليد.
  - **قفل الأمان الفوري (Driving Safety Interruption Modal)**:
    - بمجرد تجاوز السرعة **7 كم/ساعة**، يتم إيقاف اللعبة ومؤقت الجولة فورياً وإطلاق نغمة تحذيرية صوتية (`SFX.warning`).
    - تظهر شاشة تنبيه أمان تمنع اللعب أثناء القيادة ولا تختفي إلا بتوقف السيارة تماماً (0 كم/س) لضمان سلامة الطريق.
  - **مؤشر أمان مباشر (Live Safety Badge)**: يوضح حالة السيارة اللحظية (🟢 متوقف / 🔴 متحرك).
  - **محاكي تجريبي (Demo Mode)**: زر مدمج لاختبار مستشعر حركة السيارة ومحاكاتها على المتصفحات المكتبية.

---

### 3. 🎯 إعادة موازنة الصعوبة والنقاط (Professional Difficulty Re-balancing)
- **تم ضبط الصعوبة لمنع الوصول السهل لأعلى سكور**:
  - **المستوى الأول (خصم 5%)**: `1,200 نقطة` (متاح للاعبين العاديين).
  - **المستوى الثاني (خصم 10% أو إضافة مجانية)**: `2,400 نقطة` (يتطلب تركيزاً وسرعة).
  - **المستوى الثالث (مشروب the A&A مجاني أو ترقية حجم)**: `3,600 نقطة` (تحدٍّ حقيقي للأبطال يتطلب الحفاظ على الكومبو والسرعة والدقة بدون أخطاء!).
- **نظام الكومبو الصارم**:
  - الخطأ أو تفويت الهدف يكسر الكومبو ويعود به إلى الصفر فوراً، مع خصم نقاط جزائية.
  - الألعاب الـ 9 أصبحت متوازنة رياضياً وفق وتيرة كل لعبة وتصاعد مستوياتها الأربعة كل 15 ثانية.

---

### 4. 🔒 الحماية ومكافحة التحايل (Anti-Cheat & Security Hardening)
- **توقيع الجلسة بالهاش المشفر (Session HMAC / Tamper Proofing)**:
  - حماية نقاط الجلسة والفاتورة والرقم من التعديل اليدوي في الذاكرة أو `localStorage`؛ أي تلاعب يلغي الجلسة فوراً.
- **فلتر مكافحة الأوتوكليكر (Autoclicker / Rate Limiting)**:
  - تجاهل النقرات فائقة السرعة غير البشرية (أقل من 42ms أو أكثر من 11 نقرة بالثانية).
- **أكواد ترويجية مشفرة ذاتية التحقق**:
  - الكود يحمل خوارزمية تشفير تربط نوع الجائزة وتاريخ اليوم وتجزئة الـ Salt لمنع التخمين أو التزوير.
- **حماية بوابة الكاشير (`#staff`)**:
  - تشفير رمز الدخول (PIN Hash).
  - نظام حظر آلي (Brute-force Lockout) يقفل البوابة لمدة 60 ثانية بعد 3 محاولات خاطئة.
  - منع الصرف المكرر لأي كود.

---

### 5. 🔊 المؤثرات الصوتية المتطورة (Web Audio API Sound Engine)
- مؤثرات صوتية أركيد تفاعلية مبهجة مصممة بالكامل برمجياً عبر Web Audio API بدون الحاجة لأي ملفات صوتية خارجية:
  1. `tap`: نقرة خشبية ناعمة.
  2. `ok(combo)`: نغمات موسيقية تصاعدية مع كل كومبو.
  3. `miss`: نغمة خطأ منخفضة مع تنبيه بالاهتزاز.
  4. `countdown` & `go`: عد تنازلي وإشارة انطلاق حماسية.
  5. `levelUp`: نغمة تصاعدية عند ترقية المستوى كل 15 ثانية.
  6. `reward`: رنة إصدار التذكرة وصرف المكافأة.
  7. `warning`: إنذار ثنائي النبض عند رصد حركة السيارة.
  8. `win`: معزوفة احتفالية عند انتهاء الجولة.
- دعم كامل لكتم/تشغيل الصوت والاهتزازات اللمسية (Haptics).
