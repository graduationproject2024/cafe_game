# 🚗 ألعاب كافيه درايف ثرو (Drive-Thru Cafe Mini-Games)

تطبيق ويب تفاعلي سريع وممتع مخصص لعملاء الكافيه أثناء انتظار استلام طلباتهم في مسار السيارات (Drive-thru). يمنح العملاء تجربة تسلية وتنافس مع فرصة الفوز بخصومات ومكافآت حقيقية (مثل خصم 5%، 10%، أو مشروب مجاني).

---

## ✨ المميزات الرئيسية

- **9 ألعاب مصغرة متنوعة**:
  1. ☕ **اصطياد الحبوب (Beans Catcher)**: التحكم بالكوب لالتقاط حبوب البن وتفادي الحبوب المحروقة.
  2. 🥛 **صبة الكابتشينو (Pour Perfect)**: التحكم في توقيت ومستوى صب الحليب حتى العلامة المحددة.
  3. 🫧 **فقاعات البخار (Steam Bubbles)**: سرعة البديهة في فرقعة الفقاعات قبل اختفائها.
  4. 🃏 **ذاكرة الكافيه (Memory Cards)**: مطابقة كروت المشروبات والحلويات المتشابهة.
  5. ❓ **كويز القهوة (Coffee Quiz)**: أسئلة ثقافية ممتعة وسريعة عن عالم القهوة وتحضيرها.
  6. 🔁 **كرر التحضير (Simon Recipe)**: حفظ وتكرار تسلسل إعداد المشروبات بدقة.
  7. 🥤 **أين الحبة؟ (Cup Shuffle)**: متابعة الكوب الذي يحتوي على حبة البن أثناء الخلط السريع.
  8. 🔥 **ساخن أو بارد (Hot or Cold)**: تصنيف المشروبات سريعاً حسب درجة حرارتها.
  9. 🏗️ **برج الكوبايات (Cup Stack)**: موازنة وإنزال الأكواب فوق بعضها لبناء أعلى برج.

- **نظام مكافآت ذكي (Tiers & Rewards)**:
  - **1000 نقطة**: خصم 5% على الطلب.
  - **2000 نقطة**: خصم 10% أو إضافة مجانية (شوت إسبريسو / سيرب).
  - **2500+ نقطة**: مشروب مجاني بالكامل أو ترقية الحجم مجاناً.
- **توليد أكواد مشفرة ذاتية التحقق**:
  - كود فريد لكل فائز بصيغة `XXX-XXXX-XX` يربط نوع المكافأة واليوم ورمز تحقق Hash لمنع التلاعب.
- **مؤثرات صوتية واهتزازات (Web Audio API & Haptics)**:
  - مؤثرات صوتية تفاعلية مبهجة مبرمجة داخلياً (Pure Web Audio) دون الحاجة لتحميل أي ملفات صوتية خارجية، مع دعم كامل للعمل أوفلاين وخيار كتم الصوت.
- **أمان القيادة ونظام القفل التلقائي**:
  - اشتراط إقرار توقف السيارة تماماً قبل بدء اللعب.
  - إغلاق الألعاب تلقائياً وتنبيه العميل عند اقتراب موعد استلام الطلب.
- **بوابة تحقق الكاشير والموظفين (`#staff`)**:
  - صفحة مخصصة للتحقق من صلاحية الأكواد وتسجيل صرفها برقم سري.

## 🚀 كيفية التشغيل والنشر

### 1. التشغيل المحلي (Local)
المشروع عبارة عن Single Page Application بدون أي متطلبات تشغيل معقدة:
- فقط افتح ملف `index.html` في أي متصفح حديث (Chrome, Safari, Edge, Firefox).

### 2. النشر على GitHub Pages
1. ادخل إلى إعدادات المستودع على GitHub: **Settings** > **Pages**.
2. اختر الفرع: **Branch: main** ثم المجلد **/(root)** واضغط **Save**.
3. سيكون الموقع متاحاً مباشرة على:
   ```
   https://<username>.github.io/cafe_game/
   ```

## ⚙️ تخصيص الإعدادات (Configuration)

يمكن تعديل إعدادات الكافيه بكل سهولة في كائن `CFG` داخل ملف `index.html`:

```javascript
var CFG = {
  roundSeconds: 60,          // مدة الجولة بالثواني
  levelEverySeconds: 15,     // كل كم ثانية تزيد الصعوبة
  basePoints: 20,            // أساس النقاط
  tiers: [1000, 2000, 2500], // حدود النقاط لكل مرحلة
  topTierChance: 1,          // احتمالية المشروب المجاني عند تحقيق 2500 نقطة
  validDays: 3,              // صلاحية كود الخصم بالأيام
  maxWaitMinutes: 12,        // قفل الألعاب تلقائياً بعد هذه المدة
  requireOrder: true,        // اشتراط رقم الطلب للدخول
  webhookUrl: '',            // رابط Google Sheets أو Webhook لتسجيل العملاء
  salt: 'cafe-secret-drive-thru-2026', // ملح التشفير للتحقق من الأكواد
  staffPin: '2026'           // الرقم السري الافتراضي لبوابة الموظف
};
```

## 👨‍💼 كيفية استخدام بوابة الموظف (للكاشير)

1. يفتح الكاشير الرابط مضافاً إليه `#staff`:
   ```
   https://<your-domain>/#staff
   ```
2. يدخل الرقم السري للموظف (الافتراضي: `2026`).
3. يكتب كود العميل الظاهر على شاشة هاتفه، ويضغط **تحقق من الكود**.
4. يظهر نوع المكافأة وتاريخ صلاحيتها، ويتم الضغط على **تأكيد صرف المكافأة** لمنع إعادة استخدام الكود.
